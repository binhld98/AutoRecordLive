# AutoRecordLive Core Front-End

The core front-end is a React and TypeScript single-page application built with Vite. It will provide the authenticated product experience for following hosts, reviewing recordings, managing notifications, and viewing account details.

## Prerequisites

- Node.js supported by the [current Vite release](https://vite.dev/guide/)
- npm

## Quick start

From `fe/app`, install dependencies and start the local development server:

```bash
npm install
npm run dev
```

## Available scripts

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the local development server. |
| `npm run build` | Type-check and build production assets. |
| `npm run preview` | Preview the production build locally. |
| `npm run lint` | Run Oxlint on the app source. |

See the [front-end architecture](../../docs/fe-arch.md) for the planned routes, UI stack, and product responsibilities.
